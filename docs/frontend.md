# Интерфейс календаря

## Запуск

Из корня проекта: `python -m backend.app.main`. Откройте http://127.0.0.1:8100/.
HTML также доступен на `/templates/index.html`, стили — `/styles/`, скрипты — `/scripts/`.

Для просмотра оформления без сервера откройте `frontend/templates/index.html` непосредственно в браузере. В этом режиме показываются демонстрационные события, изменения недоступны. Тот же режим доступен на `/?preview=1`. Примеры не записываются в базу данных.

При первом запуске открывается страница создания локального профиля. Данные профиля доступны в настройках. Подробнее — user-profile.md.

## Навигация

- Годы: выбор из 12 лет; стрелки переключают диапазон.
- Месяцы: 12 месяцев выбранного года; стрелки переключают год.
- Недели: полная сетка 00:00–24:00; стрелки переключают неделю.
- Выбор года открывает месяцы. Выбор месяца открывает первую неделю месяца, а для текущего месяца — текущую неделю.
- Сегодня возвращает текущую неделю и прокручивает ближе к текущему времени.
- На узких экранах неделя прокручивается горизонтально; панель дня открывается поверх календаря.

Клик по свободному месту создаёт событие. Клик по карточке открывает сведения, изменение серии, перенос или отмену отдельного экземпляра и удаление события/серии. Изменения повторения с существующими исключениями требуют явного подтверждения их сброса.

## Оформление и файлы

Палитра: пергамент `#F2E6CC`, старый лист `#D7BD90`, терракота `#A85B32`, чернила `#4A392E`, шалфей `#78836B`. Системные шрифты, локальные SVG, без внешних CDN и сборщика. Учитывается настройка уменьшения анимации.

- `profile.js`: загрузка и сохранение профиля, первый запуск.
- `timezone.js`: календарное время в выбранном поясе и преобразование в UTC.
- `calendar-core.js`: даты, навигация, распределение пересекающихся карточек по колонкам.
- `icons.js`: SVG и реестр категорий `CompanionCategories`.
- `api.js`: API и отдельный режим предпросмотра.
- `dialogs.js`: формы и модальные окна.
- `app.js`: экран, панели, настройки и загрузка расписания.
- `styles.css`, `calendar.css`, `dialog.css`: оболочка, календарь, формы.

Состояние панелей, плотность строк и начальный час сохраняются в localStorage. События хранятся только на backend. Тип события category сохраняется через API и выбирается в форме. Типы: default, work, entertainment, learning, health, personal, rest. Палитра и SVG заданы в CompanionCategories.

## Время и ограничения

Показ и ввод дат используют эффективный пояс профиля: устройства в режиме system, выбранный IANA-пояс в режиме manual. Новая серия получает этот пояс; при редактировании существующей серии её пояс повторения сохраняется. API получает даты с UTC-смещением. Несуществующее местное время при переходе на летнее время отклоняется. Отдельного выбора двух вариантов времени при осеннем переводе часов пока нет.

События, проходящие через полночь, разделены визуально по дням. Пересечения занимают соседние колонки, чтобы каждая карточка оставалась доступна. Минимальная высота карточки сохраняет возможность нажать короткое событие.

Вкладка «Все события» показывает серии; восстановление отменённых экземпляров пока доступно через API. Kanban доступен во вкладке «Задачи»; описание — tasks-api.md. Чат ассистента не реализован.

## Панель дня и восстановление вкладки

Правая панель по умолчанию свёрнута до полосы с собственной кнопкой раскрытия. Внутри: мини-календарь, события на сегодня и их добавление, задачи на сегодня со счётчиком и их добавление. Новая задача из панели получает TODO и сегодняшнюю плановую дату в поясе профиля. Состояние панели и текущая вкладка сохраняются в localStorage (companion.dayPanelCollapsed, companion.currentPage). После сохранения профиля страница перезагружается с восстановлением вкладки, включая настройки. Недельная таблица содержит только события; задачи показаны в панели дня и отмечены в мини-календаре.

Название приложения в интерфейсе — Folliant. В логотипе используется курсивная антиква Palatino Linotype с локальными запасными шрифтами, без загрузки из сети.
